# Gemini Spell

A Raycast extension that uses Google's Gemini AI to check and correct spelling/grammar in selected text.

## Setup

1. Get a Gemini API key from [Google AI Studio](https://aistudio.google.com/)
2. Run `npm run dev` to install the extension
3. Configure your API key in Raycast preferences

## Usage

Select text anywhere, then use the Raycast command to check spelling and grammar with Gemini 2.5 Flash.
